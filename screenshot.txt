# Screenshot для WordPress темы

Для завершения темы нужно добавить файл screenshot.png размером 1200x900px.

## Как создать screenshot:

1. Откройте главную страницу сайта в браузере
2. Сделайте скриншот (или используйте инструмент типа Photoshop)
3. Обрежьте до размера 1200x900px
4. Сохраните как screenshot.png
5. Поместите в корень темы (рядом со style.css)

## Альтернативно:

Используйте любое изображение с барной тематикой:
- Фото барной стойки
- Коктейли
- Бармен за работой
- Мероприятие с баром

## Важно:

- Размер: 1200x900px (строго!)
- Формат: PNG
- Название: screenshot.png (строчные буквы)
- Расположение: корень темы

Без screenshot.png тема будет работать, но не будет превью в админке WordPress.
