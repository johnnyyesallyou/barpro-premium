# BarPro Premium WordPress Theme

Премиум тема WordPress для выездного бара премиум класса.

## 🎯 Описание

BarPro Premium - это полнофункциональная WordPress тема для компаний, предоставляющих услуги выездного бара. Включает калькулятор стоимости, каталог коктейлей, пакеты услуг, портфолио и маркетинговые виджеты.

## ✨ Основные возможности

### Custom Post Types (7 типов)
- **Коктейли** - каталог с составом, крепостью, ценами
- **Пакеты** - тарифные планы
- **Команда** - профили барменов
- **Кейсы** - портфолио работ
- **Отзывы** - клиентские testimonials
- **Доп. услуги** - дополнительные опции
- **Форматы кейтеринга** - форматы обслуживания (фуршет, банкет, BBQ и т.д.)

### Специальные страницы
- **Главная** (front-page.php) - с секциями: hero, пакеты, коктейли, команда, кейтеринг, отзывы
- **Меню коктейлей** (archive-cocktail.php) - каталог всех коктейлей
- **Пакеты** (page-packages.php) - детальное описание тарифов
- **Портфолио** (archive-case.php) - кейсы с фильтрацией
- **Калькулятор** (page-calculator.php) - многошаговый калькулятор стоимости
- **Кейтеринг** (page-catering.php) - полная информация о кейтеринговых услугах
- **Бар + Кейтеринг** (page-bar-catering.php) - комбо-пакеты со скидкой 15%

### Функционал
- ✅ Многошаговый калькулятор (4 шага)
- ✅ AJAX обработчики для форм
- ✅ Email захват на шаге 3
- ✅ Сохранение лидов в БД
- ✅ Метабоксы для custom полей
- ✅ Адаптивный дизайн
- ✅ Интеграция с WhatsApp
- ✅ Customizer для настроек
- ✅ Виджеты в футере (3 области)
- ✅ Меню (главное + футер)
- ✅ Поддержка миниатюр
- ✅ Custom размеры изображений

## 📦 Установка

### Способ 1: Через админку WordPress
1. Скачайте ZIP файл темы
2. Войдите в админку WordPress
3. Перейдите в **Внешний вид → Темы → Добавить новую**
4. Нажмите **Загрузить тему**
5. Выберите ZIP файл
6. Нажмите **Установить**
7. Активируйте тему

### Способ 2: Через FTP
1. Распакуйте ZIP архив
2. Загрузите папку `barpro-wp-theme` в `/wp-content/themes/`
3. Активируйте тему в админке WordPress

## 🚀 Быстрый старт

### 1. Создайте страницы

После активации темы создайте следующие страницы:

**Главная страница:**
- Создайте страницу "Главная"
- Не выбирайте шаблон (используется front-page.php автоматически)
- В **Настройки → Чтение** установите эту страницу как главную

**Страница пакетов:**
- Создайте страницу "Пакеты"
- Шаблон: **Страница пакетов**

**Страница калькулятора:**
- Создайте страницу "Калькулятор"
- Шаблон: **Калькулятор стоимости**

### 2. Добавьте контент

**Коктейли:**
1. Перейдите в **Коктейли → Добавить новый**
2. Заполните название и описание
3. В метабоксе укажите:
   - Состав
   - Алкогольный/безалкогольный
   - Крепость
   - Объём (мл)
   - Цена (₽)
4. Добавьте изображение (400x500px)

**Пакеты:**
1. Перейдите в **Пакеты → Добавить новый**
2. Заполните описание пакета
3. Добавьте метаполя (опционально через плагин ACF)

**Команда:**
1. Перейдите в **Команда → Добавить нового**
2. Добавьте биографию бармена
3. Загрузите фото (400x400px)

**Кейсы:**
1. Перейдите в **Кейсы → Добавить новый**
2. Опишите проект
3. Добавьте изображение (1200x600px)

### 3. Настройте меню

1. Перейдите в **Внешний вид → Меню**
2. Создайте меню "Главное меню"
3. Добавьте пункты:
   - Главная
   - Меню (ссылка на `/cocktails/`)
   - Пакеты
   - Портфолио (ссылка на `/cases/`)
   - Калькулятор
4. Установите расположение: **Главное меню**

### 4. Настройте виджеты

1. Перейдите в **Внешний вид → Виджеты**
2. Добавьте виджеты в области **Футер 1**, **Футер 2**, **Футер 3**

Примеры:
- Футер 1: О компании (текст)
- Футер 2: Навигация (меню)
- Футер 3: Контакты (текст)

### 5. Настройте Customizer

1. Перейдите в **Внешний вид → Настроить**
2. Заполните:
   - **Контактная информация**: телефон, email, WhatsApp
   - **Главная секция**: заголовок, подзаголовок, фон
   - **Социальные сети**: ссылки на профили
   - **Цвета темы**: золотой цвет, тёмный фон

## 📝 Метабоксы

### Коктейли
- `_cocktail_composition` - Состав (textarea)
- `_cocktail_is_alcoholic` - Алкогольный (checkbox)
- `_cocktail_strength` - Крепость (text)
- `_cocktail_volume_ml` - Объём в мл (number)
- `_cocktail_price` - Цена (number)

### Пакеты (расширяемые через ACF)
- `_package_price` - Цена
- `_package_cocktails` - Количество коктейлей
- `_package_bartenders` - Количество барменов
- `_package_hours` - Часов работы
- `_package_featured` - Featured пакет (checkbox)

### Кейсы
- `_case_category` - Категория (Корпоратив, Свадьба, и т.д.)
- `_case_guests` - Количество гостей
- `_case_location` - Локация
- `_case_date` - Дата мероприятия

### Отзывы
- `_testimonial_author` - Автор
- `_testimonial_position` - Должность
- `_testimonial_rating` - Рейтинг (1-5)

### Дополнительные услуги
- `_service_price` - Цена
- `_service_icon` - Иконка (emoji)

## 🎯 AJAX Handlers

### `calculate_price`
Расчёт стоимости в калькуляторе

**Параметры:**
- `guests` - количество гостей
- `hours` - часы работы
- `services` - массив ID выбранных услуг

**Возвращает:**
```json
{
  "original": 95000,
  "discount": 9500,
  "final": 85500
}
```

### `save_lead`
Сохранение лида

**Параметры:**
- `email` - email
- `name` - имя (опционально)
- `phone` - телефон (опционально)
- `message` - сообщение

## 🐛 Troubleshooting

### Коктейли не отображаются
1. Проверьте, что создали коктейли в админке
2. Убедитесь, что permalink настроены правильно: **Настройки → Постоянные ссылки → Сохранить**

### Калькулятор не работает
1. Проверьте, что jQuery загружается
2. Откройте консоль браузера (F12) и проверьте ошибки JavaScript
3. Убедитесь, что AJAX URL правильный

### Email не отправляются
1. Установите плагин **WP Mail SMTP**
2. Настройте SMTP сервер
