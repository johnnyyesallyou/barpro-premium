# 📦 Установка и настройка BarPro Premium

> **Версия:** 1.1.0 · **Requires:** WordPress 6.4+ · PHP 8.0+ · ACF Pro 6+

---

## ✅ Чеклист установки (по порядку)

### 1. Установить тему

1. Зайдите в **Внешний вид → Темы → Добавить → Загрузить тему**
2. Загрузите файл `barpro-premium-v10-fixed.zip`
3. Нажмите **Активировать**
4. Перейдите в **Настройки → Постоянные ссылки → Сохранить** (сбросит кэш правил URL)

---

### 2. Установить ACF Pro

Тема использует ACF Pro для полей кейсов, команды, калькулятора.

1. Скачайте `advanced-custom-fields-pro.zip` с [advancedcustomfields.com](https://www.advancedcustomfields.com/)
2. Установите через **Плагины → Добавить → Загрузить плагин**
3. Активируйте и введите лицензионный ключ

> **Без ACF Pro:** тема работает, но поля кейсов (задача/решение/галерея), данные команды и ряд hero-изображений останутся пустыми. Группы полей прописаны в `inc/tz-acf.php` через PHP API и не требуют ручного создания.

---

### 3. Синхронизировать ACF JSON (если поля уже созданы)

При установке на новый сервер ACF автоматически обнаружит группы полей из папки `acf-json/` темы.

1. Перейдите в **Пользовательские поля → Синхронизация** (вкладка появляется при наличии изменений)
2. Выберите все группы → **Синхронизировать**

> Если вкладки синхронизации нет — группы уже актуальны, ничего делать не нужно.

---

### 4. Создать страницы

При первой активации темы страницы создаются **автоматически** (хук `after_switch_theme`):

| URL | Шаблон |
|---|---|
| `/calculator` | Калькулятор стоимости |
| `/cocktails` | Меню коктейлей |
| `/catering` | Кейтеринг |
| `/bar-catering` | Бар + Кейтеринг |
| `/team` | Команда |

Страница `/cases` **не создаётся автоматически** — архив кейсов доступен напрямую через CPT archive (`/cases/`).

Если страницы не создались: **Плагины → Деактивировать тему → Активировать снова**.

---

### 5. Назначить шаблоны страницам

Если автосоздание не сработало или страницы создавались вручную:

Открыть страницу → **Атрибуты страницы → Шаблон → выбрать из списка**.

### 7. Сборка фронтенда (Production build)

**Требуется:** Node.js 18+

```bash
# В папке темы на локальной машине:
npm install
npm run build
```

После сборки папка `assets/dist/` содержит минифицированные бандлы. Тема автоматически переключается в production-режим при наличии `assets/dist/.vite/manifest.json`.

**Обязательная проверка после деплоя:** убедитесь что структура выглядит так:

```
assets/
└─ dist/
   ├─ js/
   │   └─ main.[hash].min.js
   ├─ css/
   │   └─ main.[hash].min.css
   └─ .vite/
       └─ manifest.json   ← этот файл переключает тему в production-режим
```

Если `manifest.json` отсутствует — тема работает в dev-режиме (подключаются неминифицированные файлы из `assets/js/` и `assets/css/`). Это безопасно, но замедляет загрузку.

**Быстрая проверка через wp-admin:** откройте исходный код страницы и найдите тег `<script>`. В production-режиме путь будет содержать `/dist/js/main.` с хэшем. В dev-режиме — `/assets/js/main.js` без хэша.

**На хостинге без Node.js:** загрузите папку `assets/dist/` по SFTP после сборки на локальной машине. Без сборки тема работает в dev-режиме (не минифицировано, но функционально).

## ⚡ Production build (Vite)

Тема работает в двух режимах:

- **Dev-режим** (по умолчанию): отдельные JS/CSS файлы из `assets/`. Не требует сборки. Используется на локалке и при разработке.
- **Production-режим**: минифицированный Vite bundle из `assets/dist/`. Тема переключается автоматически при наличии файла `assets/dist/.vite/manifest.json`.

### Как собрать production build

```bash
# 1. Установить зависимости (нужен Node.js 18+)
npm install

# 2. Собрать production bundle
npm run build

# 3. После сборки в assets/dist/ появится manifest.json
#    Тема автоматически начнёт использовать минифицированные файлы
```

> **На хостинге без Node.js:** загружайте папку `assets/dist/` (результат сборки) вручную через SFTP/SSH. Для большинства shared-хостингов это единственный вариант.

> **Без сборки:** тема полностью работает без `assets/dist/` — просто без минификации. Для небольшого проекта это допустимо.

## ⚠️ Кэширование AJAX (LiteSpeed / WP Rocket / FastCGI)

Если на хостинге используется серверное кэширование, добавьте `admin-ajax.php` в исключения:

**LiteSpeed Cache:**
В `.htaccess` перед основными правилами WordPress:
```apache
<IfModule LiteSpeed>
  RewriteRule ^wp-admin/admin-ajax.php - [E=Cache-Control:no-cache]
</IfModule>
```
Или в плагине LiteSpeed Cache → Исключения → URL исключения: `/wp-admin/admin-ajax.php`

**WP Rocket:**
Настройки → Кэш → Никогда не кэшировать URL: `/wp-admin/admin-ajax.php`

**Nginx FastCGI:**
```nginx
location = /wp-admin/admin-ajax.php {
    fastcgi_no_cache 1;
    fastcgi_cache_bypass 1;
}
```

## 🔧 Troubleshooting

### Проблема: Коктейли не отображаются

**Решение:**
1. Перейдите в **Настройки → Постоянные ссылки**
2. Нажмите **Сохранить изменения** (даже если ничего не меняли)
3. Это обновит правила rewrite для custom post types

### Проблема: Калькулятор не работает

**Решение:**
1. Проверьте консоль браузера (F12)
2. Убедитесь что jQuery загружается
3. Проверьте что страница использует шаблон "Калькулятор стоимости"

### Проблема: Email не отправляются

**Решение:**
1. Установите плагин **WP Mail SMTP**
2. Настройте Gmail или SendGrid
3. Протестируйте отправку через настройки плагина

### Проблема: Сайт медленный

**Решение:**
1. Установите плагин кеширования (WP Rocket, W3 Total Cache)
2. Оптимизируйте изображения (Smush, ShortPixel)
3. Используйте CDN (Cloudflare)

### Проблема: Тема не активируется

**Решение:**
1. Проверьте версию WordPress (минимум 6.0)
2. Проверьте версию PHP (минимум 7.4)
3. Проверьте лог ошибок хостинга
